# FRbox-site

Полный **сайт-оболочка (контроллер)** для [FRbox](https://github.com/DdejjCAT/FRbox) —
приватного сервера Jackbox Games.

Это статическая сборка официального сайта-контроллера Jackbox.tv с набором кастомных
патчей под FRbox: вход через Twitch, модерация контента, выбор собственного сервера,
кнопка скачивания сервера и другое.

> Здесь лежит **только сайт**. Сам сервер — в отдельном репозитории:
> **https://github.com/DdejjCAT/FRbox**

---

## Как это устроено

Сервер FRbox раздаёт этот каталог как статику (`siteRoot`). Каталог `main/` содержит
бандлы приложений и игр; `BRQY40Mb.js` — основной бандл контроллера; `index.html` —
точка входа. Раздача статики зависит от домена (`Host`):

- на основном хосте (`jack.*`) корень `/` — **панель FRbox**;
- на остальных хостах (например `jpp.*`) корень `/` — **этот сайт-контроллер**.

---

## Структура

```
index.html          точка входа (title "FRbox <3"), подключает /twitch-config.js и BRQY40Mb.js
BRQY40Mb.js         собранный бандл контроллера (патченный)
assets/             стили и статика сайта
main/               бандлы приложений и игр:
  @connect/         контроллер (Twitch-вход, выбор сервера, кнопка скачивания)
  @moderator/       приложение модерации
  pp*/ standalone*/ бандлы конкретных игр
favicon.ico, favicon-32.png, apple-touch-icon.png
manifest.webmanifest, robots.txt
```

## Кастомные изменения на сайте

1. **Вход через Twitch.** Патч `main/@connect/*` — экран логина вызывает
   `window.__twitchLogin()` (определяется в `/twitch-config.js`, который отдаёт сервер),
   открывается OAuth-редирект Twitch, результат уходит на серверные маршруты
   `/twitch/validate`, `/twitch/flow`, `/twitch/flow/status`, `/twitch/forget`.
   Комнаты с флагом `twitchLocked` пускают игрока только с валидным `twitch-token`.
   Имя и аватар подставляются из Twitch.
2. **Поле ввода кастомного сервера.** Адрес сервера берётся из query-параметров
   `?server=` / `?s=` (значение `live` → сервер по умолчанию) и показывается в форме
   подключения. Позволяет подключаться к любому FRbox-серверу без правки бандла.
3. **Кнопка «Скачать сервер FRbox».** В `index.html` задаётся
   `window.FRBOX.downloadUrl` / `window.FRBOX.downloadLabel`, а контроллер рисует
   ссылку `.frbox-download` в интерфейсе — быстрый переход к репозиторию сервера.
4. **Приложение `@moderator`.** Полноценный UI модерации: показывает отправленный
   игроками контент (текст, дудлы и т.д.), позволяет одобрять/отклонять и кикать
   игроков. Работает совместно с серверной частью модерации FRbox.
5. **Отключён cookie-consent (cookieyes).** Баннер согласия на cookie удалён/вырезан,
   чтобы не мешал работе контроллера.
6. **Прочие патчи бандлов** под домены, хосты и поведение FRbox.

## Кастомные фишки на стороне сервера (FRbox)

Чтобы сайт был полностью живым, на сервере реализовано:

- **Ecast + Blobcast** — HTTP API Ecast и WebSocket-мост на устаревший протокол
  Blobcast (Socket.IO v1).
- **Требование входа через Twitch** (`twitchLocked` / конфиг `twitch`) — валидация
  токена через `id.twitch.tv/oauth2/validate`, без собственного Twitch-приложения.
- **Модерация (`@moderator`)** — сервер сам создаёт записи `moderate:<type>:<key>`,
  рассылает их модераторам, принимает решения (одобрено/отклонено), уведомляет хост и
  обрабатывает кик игроков.
- **Фикс `passwordRequired`** — обязательность пароля для игроков определяется
  только игровым паролем комнаты, а не модераторским (раньше из-за этого просило пароль
  в комнатах без пароля).
- **Режим зеркала (MITM)** — сверка ответов с официальным сервером (`ecast-qa`
  jackboxgames.com) для отладки.
- **Обход гео-блокировок через Xray** (локальный SOCKS5), прокси к официальным
  сервисам (`/arc/`, `/arcade/`, `/binjpipe/`, `/mixpanel/`).
- **Веб-дашборд**, баны IP, защита от брутфорса.

Подробности — в README сервера: https://github.com/DdejjCAT/FRbox
